# PYPY Landing Page v7 — Showcase Edition

Mobile-first animated landing page for the PYPY exhibition QR.

## Files
- `index.html` — complete static landing page
- `assets/pypy-logo.png` — PYPY logo derived from the approved QR artwork
- `assets/doraemon.png` — exact Doraemon crop from the approved QR artwork (no new generated mascot)
- `assets/pypy-poster.png` — PYPY poster preview

## Before deployment
1. Put the final PDF at `PYPY_Report.pdf` beside `index.html`.
2. Set `WHATSAPP_NUMBER` near the bottom of `index.html` in international format, e.g. `6012xxxxxxx`.
3. Deploy the folder to GitHub Pages / Cloudflare Pages.

The page is deliberately phone-first because the intended entry point is a booth QR code. Desktop keeps the mobile experience centered.

WhatsApp button is configured. The final report remains intentionally unpublished until approval.
